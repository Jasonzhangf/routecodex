### L91-07 SSE 瞬态错误只重试/短期绕行，不拉黑 provider
- 触发：provider SSE transport、decode、malformed event、unexpected EOF 或 stream hang。
- 真源：错误链与 Runtime provider failure policy；SSE transport 只负责 framing/lifecycle，不拥有 health policy。
- 动作：业务字节提交前保持 pre-commit，进入同请求 retry/reselect；尝试耗尽后最多写 session-local transient bypass。业务字节已提交后显式结束当前流，但不得累计 provider consecutive failure、不得写 provider cooldown/probe、不得影响其他 session。
- 反模式：把 post-commit SSE 中断视作“强 provider 故障”，一次或累计写 provider-scope cooldown；或在 Server/SSE handler 重试并混合两次输出。
- 验证：正向锁 pre-commit SSE error 会 retry/reselect；反向锁 post-commit SSE error 不改变 fresh-session availability，且真实 HTTP 401/403 等非 SSE provider error 仍按 manifest policy 计数与冷却。

owned by Resp03 Chat Process; Direct hooks and Compat cannot perform it.

prose, a native function call, and standalone `<｜end▁of▁analysis｜>` and
`<|DSML|tool_calls>` labels. These declared leakage labels must be removed while

with the Direct issue. It must not call a Direct payload hook from Relay.
Governance precedes complete-attempt business admission. Label-only attempts
enter the existing typed empty-response recovery, with original upstream status
separate from the internal processing result. No client error or empty success
may substitute for exhausted transport termination.

Before implementation, `relay_control_marker_` owner and public HTTP cases must
fail on the observed label/prose/native-call shape and sole-label behavior.
Public Responses-to-Chat Relay cases validate actual first-attempt tool
declarations, execute a safe calculation producing 42, and send its matched
result into a verified follow-up. JSON and SSE, quoted/code preservation,
reasoning/refusal/content-filter business results, native invalid arguments,
candidate recovery and exhaustion have distinct assertions.

This design is not implementation or acceptance evidence. Historical general
DSML preservation tests remain applicable to literal and unrecognized content;
the explicit user policy supersedes blanket preservation of declared leaked
control frames. Source, build, load, behavior, review and integration remain
separate receipts.

The complete Responses-entry Relay path supplies its exact-attempt namespace
registry through a typed response profile. Resp03 consumes the shared grammar,
harvests complete representable function invocations in source order, preserves
raw argument strings and explicit call IDs, restores client namespace identity,
and updates only established aggregate text and candidate associations. A
recognized incomplete declared invocation rejects the entire attempt, even
beside complete siblings or prose. Unknown, literal and complete opaque
envelopes remain business content; their arguments are not thinking-tag input.

disposition. Native invalid model arguments remain available for client
correction, including alongside a harvested call.

The Runtime marks complete buffered attempts explicitly. Post-governance empty
admission and the new thinking projection run only at that boundary, never on
an isolated keepalive, delta or terminal fragment. Complete tools with partial
thinking labels keep their text bodies; paired recognized thinking becomes
reasoning; quoted examples and opaque envelope arguments remain unchanged.
This reuses the existing pure literal-aware thinking projector, not a Direct
payload hook.

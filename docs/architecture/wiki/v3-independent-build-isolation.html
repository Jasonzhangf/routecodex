Blocking Review Checks

  • Every design resource must gain a real path, owner, symbol, and red/green gate before becoming active.
  • Cargo metadata must show zero escaping dependencies and one V3-local owner for each relocated crate.
  • Root package, CI, and release must remain thin dispatchers.
  • No build identity or artifact may enter request/response/provider wire, MetadataCenter, continuation, debug, or Error payloads.
  • Global install, one aggregate restart, all health endpoints, old sample replay, and post-live DSH Review are required.

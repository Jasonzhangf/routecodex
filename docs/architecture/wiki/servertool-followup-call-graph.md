# Servertool Followup Call Graph

Status: retired.

The former server-side servertool followup and reentry graph was retired. There is no active V3 `ServertoolOutcome`, sidecar plan, followup state, or private response exit. Do not restore them under another name.

The replacement path is an ordinary tool call returned to the client, client execution, and a normal next request carrying the paired tool result. Provider-native hosted search and citations stay on the Provider contract. Historical implementation details remain in Git; this page is not a restore recipe.

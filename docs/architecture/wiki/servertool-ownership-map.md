# Servertool Ownership Map

Status: retired.

The V3 server-side servertool center, followup, engine selection, execution state, and CLI projection were retired. They have no active V3 owner, source path, resource, caller edge, config entry, or gate. Do not restore them under another name.

The replacement contract is ordinary function/custom/freeform/namespace tools with complete client call/result pairing in Req04 and Resp03, Provider-native hosted search with citations, and bounded client refill. Historical implementation details remain in Git; this page is not a restore recipe.

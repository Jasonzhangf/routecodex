6. Minimal Migration Plan

Binding → verification → evidence → edge → necessary node → architecture，最后才考虑重构。

No Rewrite
顺序动作为什么最小完成证据
1修正审计真源：移除 fixed continuation 假节点，保留 retired 历史/控制证据。先让图与 fixed enum 和 manifest 一致。Req/Resp 图与 manifest 节点完全一致。
2逐条处理 WebSearch 8 条 pending 和 SSE tree pending；能绑现有 Hook/builder 就绑定，重复边删除。主链已存在，优先补绑定。每条 edge 有 caller/callee/owner，positive + negative 通过。
3定义 WebSearchHookRequest、WebSearchResult、HookOutcome 最小 typed contract。只补现有 Hook 的 input/output。Schema、owner、scope、deadline、error 可机器验证。
4复用已有 Subagent；只有无唯一 owner 时才加 WebSearchSubagentAdapter。能复用就不新增；搜索不进入 Router/Provider re-enter。真实 subagent 调用、typed result、无 Router re-entry。
5替换 local hop 的搜索执行；保留 detection、call_id pairing、最终投影，验证 parity 后删 re-enter edge。替换唯一 owner，不重写 Response 链。同 query 等价 result；无 Req01 re-entry；失败进 Error01 → E06。
6逐 phase 消融 WebSearch state machine，只留 pairing/scope/跨轮所需状态。删除优于添加，避免第二控制真源。每个删除项有理由和回归证据。
7绑定 typed SSE tree → Resp05，保持 SSE transport core 无业务语义。已有唯一 semantic owner。JSON/SSE 同 finalized semantic；provider → client shortcut 负例失败。
8补真实入口 acceptance：JSON、SSE、Error、WebSearch Subagent、Direct、Relay。不新增治理节点，只绑定 terminal 证据。request id、main SHA、artifact hash、入口协议、结果、node trace 一致。
不做什么：不重写 Runtime；不加第二 Router；不让 Provider 直出 client；不把 SSE 提升为业务层；不在 parity 前删除旧 WebSearch；不把 continuation 假节点塞回固定骨架。

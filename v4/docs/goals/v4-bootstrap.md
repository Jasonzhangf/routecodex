# V4 Bootstrap Goal

## Boundary

- V4 owns all new source, experiments, governance contracts, compiled Active artifacts, Protected history, and Generated indexes.
- V3 is read-only for V4 work and remains the current runtime baseline.
- No V4 implementation may be added under `v3/`, `src/`, or `sharedmodule/` during bootstrap.

## First stages

```text
appsdk init
  -> environment confirmation
  -> goal clarification
  -> debug/refactor classification
  -> V4 owner/map binding
  -> first module design
```

The first semantic module is not selected until the V4 environment and ownership maps are confirmed.
